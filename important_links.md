# List of important links for working with pSSID

## 1. Link to the official pSSID docs

[pssid-docs](https://umnet-perfsonar.github.io/pSSID-docs/#about)

This is the official webiste with all relevant information. It is currently not finished, but still very useful, especially the deployment part.
There are also links to other documentations inside this docs

## 2. pSSID-gui link

[pssid-gui](https://github.com/UMNET-perfSONAR/pssid-gui2)

This is the official link to the most relevant version of pSSID-gui. Delpoyment guide is explained pretty well so it's better to follow the guide then doing it on your own.

## 3. Perfsonar tests docs

[perfsonar tools](https://docs.perfsonar.net/pscheduler_ref_tests_tools.html#trace-tests)

This is the official website where you can find all relevant info about pscheduler tests. It is really helpful for understanding of how the tests are executed and for troubleshooting.

## 4. Data pipeline

[github page](https://github.com/UMNET-perfSONAR/pssid-data-pipeline)

This is the official documentation for installind Logstash, Opensearch and Grafana
