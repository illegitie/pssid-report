# pSSID Wi-Fi Monitoring Documentation

This repository contains documentation for the pSSID-based Wi-Fi monitoring infrastructure developed during the project.

The documentation covers:

- Raspberry Pi configuration and deployment
- Ansible setup and automation
- Test VM configuration
- pScheduler test creation and configuration
- Monitoring stack setup (Logstash, OpenSearch and Grafana)
- Test scheduling
- Troubleshooting and common issues
